# Working in this repo

Notes for contributors and coding agents.

This project runs a Next.js version with breaking changes — APIs, conventions and
file structure may differ from what you remember. Read the relevant guide in
`node_modules/next/dist/docs/` before writing code, and heed deprecation notices.
<!-- END:nextjs-agent-rules -->

## Ground rules

- **Data access goes through `src/data/api.ts`.** Pages and components never import
  JSON or reach into `src/data/real/` directly.
- **NFL data is read-only** and regenerated by `python3 scripts/fetch_nfl_data.py`.
  Never hand-edit files in `src/data/real/`.
- **User data** (accounts, fan ballots, editor rankings) lives in Supabase and is
  optional — every surface must degrade gracefully when it is not configured.
- **Every player and team name is a link** to its profile or team page.
- Components stay small and reused: one `RankingTable`, one `StatLeaderCard`, one
  `PositionTabs`.

## Design

Read [DESIGN.md](DESIGN.md) before UI work. The palette is white, silver and black
only — no additional accent colors. Reuse the component classes in
`src/app/globals.css` (`.panel`, `.btn-*`, `.chips`, `.tabs`, `.meter`, `.tag`)
rather than inventing new patterns.
